Google Sheets Setup Required

This admin panel needs to be connected to a Google Sheet to store event and performer data. Here's what you need to do:

  1. Create a new Google Sheet called BSYA Database
  2. Go to Extensions > Apps Script
  3. Paste the code from google-apps-script.js in this project
  4. Run the initialSetup function once to create the tabs
  5. Click Deploy > New Deployment > Web App
  6. Set access to "Anyone" and deploy
  7. Copy the URL and paste it into js/config.js
